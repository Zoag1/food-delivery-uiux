# food-delivery-uiux
Proyek ini merupakan portofolio dan dokumentasi desain Antarmuka Pengguna (UI/UX) untuk aplikasi pemesanan makanan cepat saji (Food Delivery App) yang dirancang menggunakan Figma. Desain ini berfokus pada alur pemesanan makanan yang intuitif, pemilihan menu, add-ons, hingga alur checkout yang mudah.
